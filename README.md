# ⚽ 성모 사커 (Seongmo Soccer)

브라우저에서 바로 즐기는 **FIFA 스타일 2D 탑뷰 축구 게임**입니다.
7 대 7(골키퍼 포함) 경기, **피파온라인(FC 온라인) 방식 조작**, **태블릿 우선 터치 컨트롤**, 포메이션 기반 AI, 드리블·패스·차지 슛·감아차기·슬라이딩 태클, 세트피스(스로인·코너킥·골킥),
전/후반 경기 흐름, 경기 통계, 온라인 랭킹까지 담았습니다.

- 구글 **Apps Script 웹 앱**으로 배포하면 경기 기록이 **구글 시트**에 저장되고 모두가 같은 랭킹을 봅니다.
- `index.html` 파일을 **그냥 브라우저로 열어도** 동작합니다. 이때 기록은 그 브라우저(localStorage)에만 저장됩니다.
- 모든 팀과 선수는 **가상**이며 실제 구단·선수·브랜드와 관계가 없습니다.
- 외부 JS 라이브러리, 이미지, 음원 파일을 전혀 사용하지 않습니다. (효과음은 WebAudio 로 직접 합성)

## 📁 파일 구성

| 파일 | 설명 |
| --- | --- |
| `Code.gs` | Apps Script 서버 코드. 웹 앱 제공(`doGet`), 기록 저장(`saveMatchResult`), 랭킹 조회(`getLeaderboard`), 개인 전적(`getStats`) |
| `index.html` | 게임 전체 (HTML + CSS + JavaScript 한 파일). Apps Script 에서는 이름이 반드시 **`index`** 여야 합니다 |
| `appsscript.json` | Apps Script 매니페스트 (시간대 `Asia/Seoul`, V8 런타임, 웹 앱 설정, 권한 범위) |
| `README.md` | 이 문서 |

## 🚀 배포 방법 (Apps Script 웹 앱)

1. [script.google.com](https://script.google.com) 에 접속해 **새 프로젝트**를 만듭니다.
   - 프로젝트 이름을 `성모 사커` 등으로 바꿔 두면 찾기 쉽습니다.
2. 기본으로 있는 `Code.gs` 의 내용을 모두 지우고, 이 저장소의 **`Code.gs` 내용을 붙여넣습니다.**
3. 왼쪽 **파일 옆 `+` 버튼 → HTML** 을 눌러 새 HTML 파일을 만들고 이름을 **`index`** 로 지정합니다.
   (`.html` 은 자동으로 붙습니다.) 내용을 모두 지우고 이 저장소의 **`index.html` 내용을 붙여넣습니다.**
4. (선택) 왼쪽 **⚙️ 프로젝트 설정 → "편집기에서 'appsscript.json' 매니페스트 파일 표시"** 를 체크한 뒤,
   편집기에 나타난 `appsscript.json` 내용을 이 저장소의 **`appsscript.json` 으로 교체**합니다.
   - 하지 않아도 동작하지만, 시간대(`Asia/Seoul`)와 웹 앱 설정이 자동으로 맞춰집니다.
5. 💾 저장 (Ctrl+S / ⌘+S).
6. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
   - **유형 선택(⚙️) → 웹 앱**
   - **다음 사용자 인증 정보로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자` (로그인 없이 누구나 플레이하려면)
   - ⚠️ **학교·회사(Google Workspace) 계정**은 관리자가 외부 공개를 막아 두어 `모든 사용자` 항목이 없거나 배포가 거부될 수 있습니다.
     이때는 `<도메인> 내 모든 사용자`(같은 기관 계정으로 로그인한 사람만) 또는 `Google 계정이 있는 모든 사용자` 를 고르고,
     `appsscript.json` 의 `"webapp.access"` 도 같게 바꿔 주세요. (`"DOMAIN"` 또는 `"ANYONE"`. 기본값 `"ANYONE_ANONYMOUS"` 는 로그인 없이 누구나)
     외부 사람도 로그인 없이 쓰게 하려면 Workspace 관리자에게 Apps Script 웹 앱 외부 공유 허용을 요청하거나 개인 Gmail 계정으로 배포하세요.
7. **배포**를 누르고, 처음 한 번은 **액세스 승인**(구글 계정 선택 → 고급 → 안전하지 않은 페이지로 이동 → 허용)을 진행합니다.
   - 스프레드시트를 만들고 기록하기 위한 권한(`spreadsheets`)만 요청합니다.
8. 발급된 **웹 앱 URL** 을 친구들과 공유하면 끝! 🎉

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 같은 URL 에 반영됩니다.
> (편집 중 테스트는 **배포 → 배포 테스트** 의 `/dev` URL 을 사용하세요.)

### 기록은 어디에 저장되나요?

- 스크립트가 **특정 구글 시트에 연결된 경우**(시트에서 `확장 프로그램 → Apps Script` 로 만든 경우) 그 시트에 저장합니다.
- **독립형 스크립트**(script.google.com 에서 직접 만든 경우)라면, 첫 기록 저장 시
  **`성모 사커 경기 기록`** 이라는 스프레드시트를 배포자 드라이브에 **한 번만** 만들고,
  그 ID 를 스크립트 속성(`SEONGMO_SOCCER_SPREADSHEET_ID`)에 기억해 계속 사용합니다.
- 기록 시트 이름은 `경기기록`, 머리글은 `일시 | 닉네임 | 내 팀 | 상대 팀 | 득점 | 실점 | 결과 | 난이도 | 점수` 입니다.
- 저장된 스프레드시트가 잠시 열리지 않으면(구글 서비스 일시 오류) 새 시트를 만들지 않고 저장 실패로 알려 줍니다.
  기존 기록과의 연결을 지키기 위해서입니다. 기록 시트를 **일부러 삭제**했다면 ⚙️ 프로젝트 설정 → 스크립트 속성에서
  `SEONGMO_SOCCER_SPREADSHEET_ID` 를 지우면 다음 저장 때 새로 만듭니다.

### 서버 보안 처리

- 닉네임·팀 이름·난이도 등 모든 입력을 서버에서 다시 검증합니다. (길이 제한, 제어 문자 제거, 팀/난이도/경기 시간 화이트리스트,
  같은 팀끼리 경기 거부, 득점·실점은 **진짜 정수**만 허용하고 득점은 경기 시간 1분당 4골(최대 24골)까지만 인정)
- **점수와 승/무/패 결과는 서버가 득실점으로 직접 계산**합니다. 클라이언트가 보낸 점수는 무시합니다.
- 글자 칸(닉네임·팀·결과·난이도)은 앞에 `'` 를 붙여 **항상 텍스트로 저장**합니다.
  `=`, `+`, `-`, `@` 로 시작하는 **스프레드시트 수식 주입**을 막고, `007`·`50%`·`TRUE`·`2024-01-01` 같은 닉네임이 숫자/날짜로 바뀌지 않습니다.
- 동시에 여러 명이 저장해도 섞이지 않도록 `LockService` 로 잠금을 겁니다.
- `CacheService` 로 저장 요청을 제한합니다. (전체 1분에 30건, 같은 닉네임은 15초에 1건)
- 이름이 `_` 로 끝나는 서버 함수는 내부용이라 브라우저에서 호출할 수 없습니다.

## 🛠 clasp 로 배포하기 (선택)

터미널에 익숙하다면 [clasp](https://github.com/google/clasp) 로도 올릴 수 있습니다.

```bash
npm install -g @google/clasp
clasp login                                   # 구글 계정 로그인 (처음 한 번)
# script.google.com → 설정 에서 "Google Apps Script API" 를 켜 두어야 합니다.
clasp create --type webapp --title "성모 사커" # 이 폴더에서 새 프로젝트 생성 (.clasp.json 생성)
clasp push                                    # Code.gs, index.html, appsscript.json 업로드
clasp deploy --description "v1"              # 새 버전 배포
clasp open                                    # 편집기 열기 → 배포 관리에서 웹 앱 URL 확인
```

> ⚠️ **clasp 로 배포하면 권한 승인 화면이 자동으로 뜨지 않습니다.** 웹 앱은 `나(배포자)` 권한으로 실행되므로,
> 배포자가 한 번 승인하기 전까지 다른 사람은 "Authorization is required to perform that action" 오류를 보게 됩니다.
> URL 을 공유하기 **전에** 아래 중 하나를 꼭 해 주세요.
> 1. 편집기(`clasp open`)에서 함수 목록에서 `getLeaderboard` 를 고르고 **▶ 실행** → 권한 검토 → 계정 선택 → 고급 → 허용
> 2. 또는 배포자 계정으로 로그인한 상태에서 웹 앱 URL 을 한 번 열어 승인 화면을 진행

> `clasp create` 가 원격 프로젝트의 기본 `appsscript.json` 으로 로컬 파일을 덮어쓸 수 있습니다.
> 그런 경우 `clasp push` 전에 이 저장소의 `appsscript.json` 으로 되돌려 주세요 (`git checkout appsscript.json`).
> README.md 는 업로드할 필요가 없습니다. 필요하면 `.claspignore` 에 `README.md` 를 적어 두세요.

## 🎮 조작법

조작은 **피파온라인4 / FC 온라인 기본 키보드 배치**를 따릅니다. 이 게임은 **태블릿(아이패드·갤럭시 탭)** 을 주 기기로 설계했습니다.

### 키보드 (FC 온라인 방식)

키는 **물리적 키 위치**로 인식하므로 **한글 입력 상태(ㄴ·ㅁ·ㅈ·ㅇ 등)에서도** 그대로 동작합니다.

**공격 (우리 팀 공)**

| 키 | 동작 |
| --- | --- |
| `←↑↓→` | 이동 |
| `E` | 질주 (스태미나 소모) |
| `S` | 짧은 패스 — 입력 방향의 동료에게 자동 연결, **길게 누를수록 세고 멀리** |
| `A` | 로빙 패스 · 상대 진영 측면 끝(바이라인 근처)에서는 **크로스** |
| `W` | 스루 패스 (땅볼, 동료 앞 빈 공간으로) |
| `Q` + `W` | 로빙 스루 패스 (`Q` 를 누른 채 `W`) |
| `D` | 슛 — 누르고 있으면 **파워 게이지** 충전, 떼면 슛 (방향키 위/아래로 조준) |
| `Q` + `D` | 감아차기 — 힘은 약하지만 정확하고, 공이 휘어 들어갑니다 |
| `C` | 개인기 · 탈압박 — 순간 가속 + 잠깐 태클 면역 (쿨타임 2초) |

**수비 (상대 공 / 떠 있는 공)**

| 키 | 동작 |
| --- | --- |
| `Q` | 선수 전환 (공에 가장 가까운 선수) |
| `S` 누르고 있기 | 압박 · 견제 — 공 가진 상대와 우리 골대 사이로 자동으로 따라붙고, 붙으면 태클 |
| `D` | 스탠딩 태클 |
| `A` | 슬라이딩 태클 (쿨타임 1.5초) |
| `C` 누르고 있기 | 팀원 압박 — 가까운 동료 한 명이 함께 압박 |
| `W` 누르고 있기 | 골키퍼 전진 |
| `E` | 질주 |

**세트피스 · 기타**

| 키 | 동작 |
| --- | --- |
| `S` / `Space` | 킥오프 · 짧은 패스(스로인·골킥·코너킥) |
| `A` | 로빙 (코너킥은 크로스) |
| `W` / `D` | 스루 / 롱킥 (코너킥 `D` 는 강한 크로스, 스로인 `D` 는 롱 스로인) |
| `Esc` / `P` | 일시정지 |
| `M` | 소리 켜기/끄기 |
| `Enter` / `Space` | 하프타임 화면에서 후반 시작 |

- 수비할 때는 공과 가장 가까운 선수로 **자동 전환**도 됩니다.
- 닉네임 입력 칸에 글자를 칠 때는 게임 키가 동작하지 않습니다.

### 태블릿 · 터치 (FC 온라인 M 방식)

터치가 되는 기기(아이패드 사파리의 '데스크톱 웹사이트' 모드 포함)에서는 자동으로 가상 컨트롤이 나타납니다.
여러 손가락 동시 입력을 지원하므로 **조이스틱을 움직이면서 슛·패스 버튼**을 누를 수 있습니다.
버튼 크기는 화면 크기에 맞춰 커지며(아이패드 기준 약 65~140px), 이름은 공격/수비 상황에 따라 자동으로 바뀝니다.

| 위치 | 버튼 | 공격 중 | 수비 중 |
| --- | --- | --- | --- |
| 왼쪽 화면 | 조이스틱 | 아무 곳이나 누르면 손가락 아래에 생김 → 이동 | 이동 |
| 오른쪽 아래 (가장 큰 버튼) | 슛 / 태클 | 길게 눌러 파워 슛 (버튼 둘레에 게이지) | 스탠딩 태클 |
| 오른쪽 | 패스 / 압박 | 짧은 패스 (길게 = 세게) | 누르고 있는 동안 압박 |
| 오른쪽 | 스루 / GK 전진 | 스루 패스 | 누르고 있는 동안 골키퍼 전진 |
| 오른쪽 | 로빙·크로스 / 슬라이딩 | 로빙 패스, 측면 끝에서는 크로스 | 슬라이딩 태클 (쿨타임 표시) |
| 오른쪽 | 질주 | 누르고 있는 동안 질주 | 질주 |
| 오른쪽 | 개인기 / 팀원압박 | 개인기 · 탈압박 (쿨타임 표시) | 누르고 있는 동안 팀원 압박 |
| 오른쪽 위 (작은 버튼) | Q / 전환 | **한 번 누르면 파랗게 켜짐** → 다음 스루 = 로빙 스루, 다음 슛 = 감아차기 (다시 누르면 꺼짐, 누른 채 함께 눌러도 됨) | 선수 전환 |
| 화면 오른쪽 위 | ⏸ / 🔊 | 일시정지 / 소리 | |

**태블릿 팁**

- **가로 모드**를 권장합니다. 세로 모드도 지원하며, 이때는 카메라가 공격 방향을 더 앞서 보여 주고 버튼에 가려지지 않게 경기장을 위쪽에 맞춥니다.
- 사파리(공유 버튼 → **홈 화면에 추가**) 또는 크롬(메뉴 → **홈 화면에 추가**)으로 추가해 열면 주소창 없이 더 넓은 화면으로 즐길 수 있습니다.
- 태블릿에 블루투스 키보드를 연결해 키를 누르면 화면 버튼이 숨겨지고, 화면을 다시 터치하면 나타납니다.
- 두 번 탭 확대·핀치 확대·당겨서 새로고침은 경기 중 막혀 있습니다. 앱을 전환하거나 화면이 꺼지면 자동으로 일시정지되고 누르고 있던 버튼도 모두 풀립니다.

## ✨ 게임 특징

- **경기 흐름**: 타이틀 → 경기 설정(내 팀·상대 팀, 난이도 쉬움/보통/어려움, 경기 시간 2/4/6분, 닉네임) → 킥오프 → 전반 → 하프타임(통계) → 후반 → 경기 종료 → 결과 화면 → 기록 저장 → 랭킹
- **가상 팀 8개**: 팀마다 홈/원정 유니폼과 공격·수비·스피드 능력치가 다릅니다. 유니폼 색이 비슷하면 자동으로 원정 유니폼으로 바꿉니다.
- **7 대 7, 2-3-1 포메이션**: 등번호 표시, 조작 중인 선수 위 노란 화살표와 발밑 링, 스태미나 바, 슛 파워 바.
- **공 물리**: 구름 마찰, 높이(z)와 그림자(로빙·크로스·강슛은 공이 뜸), 바운드, 골대·크로스바 맞고 튕김,
  공이 골라인을 **완전히** 넘고 크로스바 아래일 때만 골 인정, 터치라인/골라인 아웃 → 스로인·골킥·코너킥 자동 진행.
- **드리블과 경합**: 공이 발 앞에 붙어 다니고, 몸싸움·스탠딩 태클·슬라이딩 태클의 성공 여부는 팀 능력치와 운으로 결정됩니다. 헤딩도 있습니다.
- **FC 온라인식 기술**: 패스 세기 게이지, 로빙 스루, 측면 크로스, 공이 실제로 휘는 감아차기, 개인기(탈압박), 압박·팀원 압박·골키퍼 전진.
- **AI**: 공 위치에 따라 움직이는 포메이션, 빈 공간으로 침투, 패스 받을 위치 잡기, 1~2명 압박, 대인 마크,
  차단 위험을 따진 패스 선택, 거리·각도를 본 슈팅, 골키퍼 포지셔닝·다이빙 선방·캐치 후 배급.
  난이도에 따라 AI 속도·반응 속도·패스/슛 정확도·골키퍼 능력이 달라집니다.
- **연출**: 카메라가 공을 부드럽게 따라가는 넓은 경기장, 관중석·광고판, "골!!" 배너와 슬로모션, 해설 자막("선방!", "골대 강타!" 등),
  상단 스코어보드(팀 약칭·유니폼 색·점수·경기 시간·전/후반), 하단 미니맵(터치 화면에서는 오른쪽 위).
- **사운드**: 휘슬, 킥, 골대 소리, 관중 함성 모두 WebAudio 로 합성. 🔊 버튼으로 음소거.
- **안정성**: 창이 포커스를 잃거나 탭을 전환하면 자동 일시정지, 네트워크 오류 시 안내 메시지와 다시 시도 버튼.

### 점수 계산 (랭킹)

```
기본 = 승 300 / 무 100 / 패 0
점수 = (기본 + 득점×50 − 실점×20 + 골득실(양수일 때)×30) × 난이도 배율
난이도 배율 = 쉬움 ×1, 보통 ×1.5, 어려움 ×2   (0점 미만은 0점)
```

예) 보통 난이도에서 3:1 승리 → (300 + 150 − 20 + 60) × 1.5 = **735점**

## ❓ 문제 해결

| 증상 | 해결 |
| --- | --- |
| 랭킹이 "오프라인 모드"로 나와요 | 파일을 직접 연 경우 정상입니다. 웹 앱 URL 로 접속하면 온라인 랭킹을 사용합니다 |
| "서버 오류" 메시지 | 배포 시 권한 승인을 했는지, 최신 버전으로 배포했는지 확인하세요. Apps Script 편집기의 **실행** 로그에서 원인을 볼 수 있습니다 |
| 키보드가 안 먹어요 | 게임 화면을 한 번 클릭해 포커스를 주세요 (웹 앱은 iframe 안에서 실행됩니다). 조작은 FC 온라인 배치(`S` 패스, `D` 슛, `W` 스루, `A` 로빙, `E` 질주)이며 이동은 방향키만 사용합니다 |
| 소리가 안 나요 | 브라우저 정책상 첫 클릭/터치 이후부터 소리가 납니다. 🔊 버튼이 음소거 상태인지 확인하세요 |
| 수정한 코드가 반영되지 않아요 | 배포 관리에서 **새 버전**으로 다시 배포해야 합니다 |
| "Authorization is required" 오류 | 배포자가 아직 권한을 승인하지 않았습니다. 편집기에서 `getLeaderboard` 를 한 번 **▶ 실행**해 승인하세요 (clasp 배포 시 특히) |
| 배포할 때 `모든 사용자` 가 없어요 / "액세스 거부" | 학교·회사(Workspace) 계정의 관리자 정책입니다. `<도메인> 내 모든 사용자` 로 배포하고 `appsscript.json` 의 `webapp.access` 를 `"DOMAIN"` 으로 바꾸거나, 관리자에게 외부 공유 허용을 요청하세요 |
| "기록 스프레드시트를 열 수 없습니다" | 구글 서비스 일시 오류면 잠시 후 다시 시도하세요. 시트를 삭제했다면 스크립트 속성 `SEONGMO_SOCCER_SPREADSHEET_ID` 를 지우세요 |
